# 🎬 Movie Recommendation System

A responsive movie recommendation web application built using HTML, CSS, and JavaScript with OMDb API integration.

## 🚀 Features
- Search movies instantly
- Press Enter to search
- Dynamic movie recommendations
- IMDb and Rotten Tomatoes ratings
- Responsive UI
- Dark themed modern design
- API integration using OMDb

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OMDb API
